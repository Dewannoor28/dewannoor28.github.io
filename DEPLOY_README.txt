DEWAN NOOR — PORTFOLIO_OS

GitHub Pages deployment:
1. Extract this ZIP.
2. Put every extracted file/folder in your repository root.
3. GitHub -> Settings -> Pages -> Deploy from a branch.
4. Branch: main. Folder: /(root). Save.

Open index.html locally to inspect content. For full browser behavior, GitHub Pages or a local HTTP server is recommended.

Edit personal content in data.js.
Edit visuals in styles.css.
Edit interaction/animation in app.js.

Keyboard shortcut: Ctrl/Cmd + K opens the command palette.
